# Problem 2

Create a data frame comprised of:

a random sample of size 10 from a standard Normal distribution a logical
vector indicating whether elements of the sample are greater than 0 a
character vector of length 10 a factor vector of length 10, with 3
different factor “levels”

``` r
set.seed(3)
df = 
  tibble(
    random_sample = rnorm(10),
    vec_logical = random_sample > 0,
    vec_character = c("apple", "banana", "broccoli", "kiwi", "grapes", "raspberry", "potato", "onion", "garlic", "ginger"),
    vec_factor = factor(sample(c("low", "medium", "high"), size = 10, replace = TRUE))
  )

df
```
