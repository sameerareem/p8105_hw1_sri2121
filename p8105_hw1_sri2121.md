df =

The mean of random_sample is -0.0671357.  
The mean of vec_logical is 0.6.  
The mean of vec_character is NA.  
The mean of vec_factor is NA.  

Here, we get the mean for random_sample and vec_logical but for
vec_character and vec_factor, the output is NA.  
This is because random_sample is a numerical variable and vec_logical
codes TRUE as 1 and FALSE as 0, so it gives out a numerical value to
calculate mean from.  
This is not the case for vec_character and vec_factor. Since there’s no
numerical value attributed to either variables, it calculates mean as
NA.

Converting variables from one type to another:

``` r
vec_logical_numeric = as.numeric(df$vec_logical)
vec_character_numeric = as.numeric(df$vec_character)
```

    ## Warning: NAs introduced by coercion

``` r
vec_factor_numeric = as.numeric(df$vec_factor)
```

When we convert the logical, character and factor variable to numeric,
the logical variable gives an output of either 0 or 1. This is because
the logical vector TRUE is coded as 1 and FALSE is coded as 0 as already
mentioned. The factor variable gives an output of 1, 2 or 3. This is
because the factor levels are stored as integers. The character vector
gives an output of NA, since there’s no numerical value R can attribute
it to.
